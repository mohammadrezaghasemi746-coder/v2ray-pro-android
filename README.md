# V2Ray Pro — نسخه اندروید (مبتنی بر معماری NovaLink)

پروژه **V2Ray Pro (نسخه 2.1.0)** نسخه بومی اندروید (Kotlin + Jetpack Compose + Android `VpnService` + هسته `Xray-core`) از پروژه دسکتاپ **NovaLink** است که دقیقاً مطابق با طراحی نئونی ارسالی شما و با انیمیشن‌های فیزیکی فوق‌روان مشابه iOS (`Spring Physics`) پیاده‌سازی شده است.

## ویژگی‌های کلیدی معماری
1. **بدون هیچ‌گونه کانفیگ دمو یا پیش‌فرض (Zero Demo Configs):** برنامه در شروع اولیه کاملاً تمیز و بدون سرورهای نمایشی یا ساختگی بالا می‌آید تا فقط کانفیگ‌ها و لینک‌های اشتراک واقعی خودتان را وارد کنید.
2. **طراحی نئونی V2Ray Pro و حرکت‌های روان در سطح iOS:** استفاده از منحنی‌های فنری (`Spring(dampingRatio = 0.78f)`)، افکت‌های شیشه‌ای (Glassmorphism)، فونت‌های مدرن و لوگوی اختصاصی نئونی V2Ray Pro.
3. **آی‌پی استاتیک (Static IP) و محافظت ۴ لایه عدم نشت آی‌پی (Zero-Leak Shield):**
   - تخصیص آی‌پی استاتیک به رابط تونل (`10.200.200.2/30`) و قابلیت قفل روی آی‌پی خروجی اختصاصی (`sendThrough` / Exit IP Pinning).
   - مسدودسازی کامل نشت IPv6 (`::/0 Sinkhole` و `UseIPv4`).
   - هدایت تمام درخواست‌های DNS به داخل تونل رمزنگاری‌شده از طریق **Remote DoH** (`https://1.1.1.1/dns-query`).
   - مسدودسازی پورت‌های UDP مربوط به **WebRTC STUN/TURN** (`3478, 3479, 5349, 19302`) و **Kill Switch** سخت‌افزاری اندروید (`Always-On VPN`).
4. **تست شبکه و نشت در لحظه (Real-Time Network & Leak Diagnostics):** سنجش واقعی پینگ TCP، تأخیر HTTP 204، نوسان (Jitter)، سرعت دانلود/آپلود و بررسی ۵ مرحله‌ای عدم نشت IPv4/IPv6/DNS/WebRTC.
5. **قابلیت آپدیت‌پذیری دوره‌ای (Periodic OTA Updater):** به‌روزرسانی خودکار و دستی برای هسته `Xray-core`، دیتابیس‌های مسیریابی `GeoIP/GeoSite`، اشتراک‌ها و نسخه برنامه با بررسی اصالت `SHA-256`.
